# usage-limits

Полоса над полем ввода Claude Code с лимитами Claude: 5-часовой и недельный,
шкала из сегментов со светофорной окраской, проценты и время до сброса.
Данные берутся из ответов модели, мод никуда сам не обращается.

## Установка

В сессии Claude Code введи:

```
/plugin install usage-limits --marketplace bolfaa-cloud/usage-limits
```

Подтверди добавление маркетплейса (`y`) и выбери область установки.

Или из терминала:

```
claude plugin install usage-limits --marketplace bolfaa-cloud/usage-limits
```
